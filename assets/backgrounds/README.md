# Background art

`space-pixel-art.png` is the single runtime background. It is an original
pixel-art space scene generated for this project: Earth, a crescent moon,
stars, a distant station, and nebula clouds. It contains no third-party
artwork, logos, or characters and may be used with this project without
attribution.

The renderer draws the 1280 × 720 image at the game’s native resolution.
Keep replacement backgrounds at 1280 × 720, pixel art, and avoid important
gameplay details in the bottom 80 pixels.
